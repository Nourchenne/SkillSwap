# Contributing to SkillSwap

Thank you for your interest in contributing to SkillSwap! 🎉

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/skillswap.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Test your changes
6. Commit: `git commit -m "Add your feature"`
7. Push: `git push origin feature/your-feature-name`
8. Open a Pull Request

## Development Setup

Follow the installation instructions in [README.md](README.md)

## Code Style

- Follow PEP 8 guidelines
- Use meaningful variable names
- Add docstrings to functions and classes
- Keep functions small and focused

## Testing

Before submitting a PR:

```bash
# Run tests
python manage.py test

# Check code style
flake8 apps/

# Run the development server
python manage.py runserver
```

## Pull Request Guidelines

1. **Title**: Clear and descriptive
2. **Description**: Explain what and why
3. **Screenshots**: If UI changes, include screenshots
4. **Tests**: Add tests for new features
5. **Documentation**: Update docs if needed

## Reporting Bugs

Use GitHub Issues with:
- Clear title
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
- Your environment (OS, Python version, etc.)

## Feature Requests

Open an issue with:
- Clear description of the feature
- Use cases
- Why it would be valuable

## Questions?

Feel free to ask questions by opening an issue!
